# Project Report

## Project Name

**Watt From Waste: Solar Monitoring System**

## Objective

Build an IoT-enabled solar monitoring prototype capable of measuring electrical output and supporting maintenance through a waterless cleaning mechanism.

## Problem

Solar-panel performance can be affected by dust accumulation and operating conditions. Monitoring electrical output provides information about system behavior, while a waterless cleaning approach can reduce reliance on water for maintenance.

## Solution

The prototype combines:

- Solar electrical sensing
- Arduino Nano
- ESP8266 Wi-Fi
- ThingSpeak cloud monitoring
- Voltage/current analytics
- Vibration + motor based waterless cleaning

## Engineering Workflow

**Collect → Transmit → Store → Display → Alert → Improve**

## Expected Outcome

The system provides a structured way to monitor solar output remotely and connect monitoring information with a maintenance mechanism.
